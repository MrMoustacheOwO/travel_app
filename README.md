# Учёт поездок — Flutter (Android)

Приложение реализует все экраны со схемы: Главная страница, Форма добавления
поездки, Страница поездки, Форма добавления активности, Страница расходов,
Форма добавления расхода, Страница участников, Форма добавления участника,
Настройки профиля и общий Подвал (нижняя навигация).

## Архитектура и хранение данных

* Все данные (поездки, участники, активности, расходы, профиль) хранятся
  **локально на устройстве** в SQLite (пакет `sqflite`). Поэтому при
  повторном запуске приложения все данные остаются на месте.
* Доступ к данным идёт только через слой репозиториев
  (`lib/data/repositories/*_repository.dart`): в каждом файле есть
  абстрактный интерфейс (`TripRepository`, `ExpenseRepository` и т.д.)
  и локальная SQLite-реализация (`Local...Repository`).
* Это сделано специально для будущего подключения к серверу/БД: когда
  появится бэкенд, нужно будет написать, например, `ApiTripRepository
  implements TripRepository`, который вместо SQL-запросов будет ходить
  в REST API, и подставить его в `lib/main.dart` вместо `LocalTripRepository`.
  Экраны и провайдеры (`lib/providers/*`) при этом менять не придётся.
* У каждой модели (`lib/models/*.dart`) уже есть `id` (uuid), поле
  `synced` и `remoteId`, а также метод `toJson()` — задел на будущую
  синхронизацию с сервером.
* Состояние экранов реализовано через `provider` (ChangeNotifier),
  что позволяет легко расширять логику без переписывания UI.

## Как получить рабочий Android-проект

В этом архиве есть только код Dart-приложения (`lib/`) и `pubspec.yaml` —
папки `android/`, `ios/` и служебные файлы Flutter-проекта не включены,
их должен сгенерировать Flutter SDK на вашей машине. Порядок действий:

1. Установите Flutter SDK (https://docs.flutter.dev/get-started/install),
   если ещё не установлен, и Android Studio с Android SDK.
2. Создайте новый пустой Flutter-проект:
   ```
   flutter create --org com.example --project-name travel_expenses_app travel_expenses_app
   ```
3. Скопируйте из этого архива файлы `pubspec.yaml` и папку `lib/`
   в созданный проект, заменив автоматически созданные заглушки.
4. Установите зависимости:
   ```
   cd travel_expenses_app
   flutter pub get
   ```
5. Подключите Android-устройство или запустите эмулятор и выполните:
   ```
   flutter run
   ```
