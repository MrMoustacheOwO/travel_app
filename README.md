# Учет поездок — Flutter (Android)

Приложение реализует все экраны со схемы: Главная страница, Форма добавления
поездки, Страница поездки, Форма добавления активности, Страница расходов,
Форма добавления расхода, Страница участников, Форма добавления участника,
Настройки профиля и общий Подвал (нижняя навигация).

## Supabase, авторизация и офлайн-данные

* Регистрация, вход, восстановление сессии и профиль используют Supabase
  Auth/PostgreSQL. Профиль создается триггером `handle_new_user` из основной
  Supabase-схемы.
* Поездки, участники, активности и расходы сначала записываются в SQLite.
  При входе и восстановлении подключения к интернету локальные записи
  синхронизируются с Supabase, а серверные данные загружаются в локальный кэш.
  Удаления сохраняются в локальной очереди, чтобы применить их онлайн.
* Во время синхронизации отображается индикатор. Если соединение не
  восстановилось за 10 секунд, приложение сообщает об ошибке и сохраняет
  локальные данные.
* В Supabase SQL Editor должна быть применена основная схема проекта, затем
  примените `supabase/migrations/202611142007_add_app_data.sql`. Миграция добавляет
  JSONB-поля, необходимые для сохранения полей моделей, которых нет в ER-схеме.
* URL и publishable key Supabase не хранятся в исходниках. Передавайте их при
  запуске или сборке через `--dart-define`:
  ```
  flutter run \
    --dart-define=SUPABASE_URL=https://your-project.supabase.co \
    --dart-define=SUPABASE_PUBLISHABLE_KEY=your-publishable-key
  ```
  Оставляйте включенными RLS-политики из основной схемы и используйте только
  publishable key, не service-role.

## Как получить рабочий Android-проект

В этом архиве есть только код Dart-приложения (`lib/`) и `pubspec.yaml` —
папки `android/`, `ios/` и служебные файлы Flutter-проекта не включены,
их должен сгенерировать Flutter SDK на вашей машине. Порядок действий:

1. Установите Flutter SDK (https://docs.flutter.dev/get-started/install),
   если еще не установлен, и Android Studio с Android SDK.
2. Создайте новый пустой Flutter-проект:
   ```
   flutter create --org com.example --project-name travel_expenses_app travel_expenses_app
   ```
3. Скопируйте из этого архива файлы `pubspec.yaml` и папку `lib/`
   в созданный проект, заменив автоматически созданные заглушки.
4. Установите зависимости:
   ```
   cd travel_expenses_app
   flutter pub get
   ```
5. Подключите Android-устройство или запустите эмулятор и выполните:
   ```
   flutter run
   ```
